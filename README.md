# Economic Courier / eCS World Wide Express, Bhilwara

> **Professional Website & Client Proposal Project**  
> Serving the textile hub of Bhilwara, Rajasthan with domestic express and worldwide courier solutions.

---

## 1. Project Overview

This repository hosts the planning, design specification, and implementation codebase for the official website of **Economic Courier / eCS World Wide Express** based in Bhilwara, Rajasthan, India.

The project is structured as a **client proposal and high-end portfolio showcase**. Its primary purpose is to present a modern, custom-crafted digital presence to the business owner, replacing outdated or non-existent web touchpoints with a fast, mobile-first, conversion-oriented experience tailored to Bhilwara’s industrial and retail logistics needs.

---

## 2. Core Brand & Business Context

- **Business Names:** Economic Courier (locally recognized trade identity) / eCS World Wide Express (express logistics & international network branding).
- **Location:** Bhilwara, Rajasthan, India (renowned as the *Textile City of India*).
- **Core Value Proposition:** Express domestic dispatch, international document and parcel delivery, specialized textile fabric sample logistics, and dedicated B2B/B2C courier handling.
- **Visual Direction:** Premium, contemporary, non-generic. Crisp white/light canvas, deep corporate navy blue, vibrant energetic brand red accents, generous whitespace, refined card elevations, and purposeful micro-interactions.

---

## 3. Ground Rules & Operational Integrity

To maintain absolute professional integrity when pitching to the business owner:
1. **No Fake Tracking Deception:** Until live API credentials from carrier networks (or proprietary consignment software) are integrated, the tracking UI is strictly marked as a demonstration interface with clear inquiry routing.
2. **No Invented Business Metrics:** Testimonials, delivery statistics, pricing tables, GST numbers, and partner affiliations remain explicitly tagged as `[PENDING CLIENT CONFIRMATION]` until verified by the owner.
3. **No Phantom Form Submissions:** Contact forms and rate inquiries connect directly to verified channels (e.g. WhatsApp Business / mailto / verified API endpoint) rather than simulating submission without a backend.

## 5. Technology Stack (Planned)

- **Framework:** Next.js (App Router, Server Components + Client Islands)
- **Language:** TypeScript
- **Styling:** Vanilla CSS / Modern CSS Modules with Root CSS Custom Properties
- **Icons:** Lucide React
- **Animations:** Framer Motion / Motion + CSS hardware-accelerated transitions
- **Deployment:** Vercel / Edge Network
