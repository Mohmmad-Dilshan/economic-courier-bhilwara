# Packaging & Parcel Logistics Photography (`public/assets/parcels/`)

This directory is designated for authentic photographs of packages, fabric swatches, and parcel handling procedures.

## Target Assets
1. `textile-swatch-packaging.webp` — Fabric swatch folders and textile sample parcels packaged for priority courier transit.
2. `barcoded-consignment.webp` — Package with barcoded label sleeve.
3. `tamper-evident-seal.webp` — Demonstration of waterproof, tamper-evident outer envelopes.

## Standards
- Ensure any visible private customer details, phone numbers, or addresses on shipping labels are cleanly blurred or anonymized.
